# Brand marks in this directory

`logo_*.xml` files generated from Simple Icons
(https://github.com/simple-icons/simple-icons), released under CC0 1.0
Universal (public domain). Each is that project's single 24x24 path, filled
with the brand's published colour.

The icons are public domain; the *brands* are not. Each mark remains the
trademark of its owner and appears here only to label a record the user chose
to store. Brands that asked Simple Icons to delist them are not included and
must not be re-added from elsewhere -- those records fall back to a monogram,
which is what the fallback is for.

The older, full-colour logo_*.xml files predate this and came from a keyed
logo API; they are not from Simple Icons.
