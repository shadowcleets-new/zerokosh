# Play "What's new" — v0.2.0 (versionCode 3)

Play caps each language's release notes at **500 characters**. Every block
below is within that; `design/check_listing.py` is not wired to this file, so
the counts in the comments were measured when it was written.

Paste the English into **Release notes** for `en-US`. The rest are here for
whenever the store listing itself is localised — Play keeps a separate field
per language, and a release about languages reading only in English would be
an odd look.

---

```

```
